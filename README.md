**MADHAV ECOMMERCE SALES DASHBOARD**

A professional and interactive Power BI dashboard project created to analyze ecommerce sales performance, customer trends, profit distribution, and payment insights using visual analytics.

**📌 Project Overview:-**
This project presents an interactive Ecommerce Sales Dashboard developed using Power BI.
The dashboard helps in understanding:
Total Sales Amount
Total Profit
Quantity Sold
Average Order Value (AOV)
State-wise Sales Performance
Category-wise Quantity Distribution
Monthly Profit Analysis
Payment Mode Analysis
Customer-wise Sales Contribution
Sub-category Profit Insights
The main objective of this project is to transform raw ecommerce data into meaningful visual insights for better business decision-making.

**📊 Key Insights:-**
Maharashtra generated the highest sales amount.
Clothing category contributed the maximum quantity sold.
COD (Cash on Delivery) was the most preferred payment mode.
Printers produced the highest profit among sub-categories.
Some months showed negative profit, indicating possible operational losses.
Top customers contributed significantly to total revenue.
